# 🤖 AI Robots Store

Современная витрина умных роботов (**Cozmo**, **Vector**, **EMO**) в стиле нео-брутализма с интерактивным выбором моделей, расцветок и подсчётом стоимости заказа.

🔗 **Демо сайта:** [airobotsnew.netlify.app](https://airobotsnew.netlify.app)

---

### ✨ Возможности
* **Выбор модели и цвета** — динамическое обновление цены и названия товара.
* **Интерактивный счётчик** — мгновенный пересчёт итоговой суммы.
* **Адаптивный дизайн** — кибер-фон и контрастные карточки с плавной анимацией кнопок.

### 🛠 Стек технологий
* **HTML5** — семантическая разметка карточек товаров.
* **CSS3** — Flexbox, стилизация в духе нео-брутализма, шрифт *Inter*.
* **JavaScript (Vanilla)** — независимая логика для каждой карточки товара.
